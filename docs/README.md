# MorningShield Documentation

This directory stores living documentation for **MorningShield**—covering environment setup, agent skills, feature architecture, and lessons learned while building on Expo SDK 57 / React Native 0.86.

- **[Lessons Learned](./lessons-learned.md)** — Troubleshooting notes, SDK 57 / RN 0.86 gotchas, and environment tips discovered during development.
